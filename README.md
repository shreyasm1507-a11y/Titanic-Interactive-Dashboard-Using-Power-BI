# Titanic-Interactive-Dashboard-Using-Power-BI
Objective: Develop an interactive dashboard to explore Titanic passenger survival data.

Tool: Microsoft Power BI Desktop.

Dashboard Features

Total passenger count.

Survival comparisons by gender.

Survival comparisons by passenger class.

Interactive filters for gender, passenger class, and survival status.

Methodology

Imported the Titanic dataset into Power BI.

Created summary cards and visualizations.

Compared survival patterns across passenger groups.

Added interactive slicers to filter the dashboard.

Saved the report as a Power BI .pbix file.

Deliverables

Titanic_Survival_Dashboard.pbix

Dashboard screenshots.

Dashboard summary report.
